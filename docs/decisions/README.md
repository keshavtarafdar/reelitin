# Architecture decision records

This folder contains decisions that are expensive to reverse or that need to stay consistent across parallel work.

- [`adr/0001-backend-foundation.md`](../adr/0001-backend-foundation.md) — accepted ASP.NET Core, EF Core, MySQL, Identity, and migration-account foundation.

Create the next numbered ADR when a new cross-cutting decision is accepted. Include context, the decision, alternatives or constraints considered, and consequences. Do not use an ADR to turn an unapproved roadmap item into implementation authorization.
