# Learning context

This folder stores concise, cumulative learning-state summaries for explicitly completed Reel It In tutoring or implementation phases. It is not a transcript archive.

When a phase is explicitly marked complete, update the relevant summary (or create one named for that phase) with:

- material taught and the key concepts;
- authoritative sources used;
- demonstrated mastery and quiz evidence;
- explanations or examples that made ideas click;
- misconceptions or sticking points;
- items to revisit later; and
- the next knowledge boundary.

Keep observations evidence-based and brief. Do not record a phase as complete merely because a conversation or coding turn ended. Do not duplicate the whole roadmap or raw chat history here.
