# Product context

This folder holds durable product context that is useful across parallel Reel It In development phases.

The current product direction is maintained in [`../ROADMAP.md`](../ROADMAP.md), including the iPhone-first experience, focus-session reward rules, portrait/landscape split, and staged development order. The root [`../../README.md`](../../README.md) contains the current high-level app description and legacy usage notes.

Add product decisions here only when they are stable enough to guide multiple phases. Keep exploratory ideas in the active phase discussion until they are explicitly accepted.
