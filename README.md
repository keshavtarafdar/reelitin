##### Active Builds

1. https://testflight.apple.com/join/C6Zue86x
    - Requires an iOS device
    - Download TestFlight then download the app from TestFlight
2. Usage instructions
    - Create an account in the login page
    - Navigate to the gameplay section of the app
    - Move the player with the joystick and cast by dragging back from the player
    - To interact with the shop click on the bubble pop up
    - Sell items by dragging them over the shop UI
    - To focus, navigate to the focus page
    - Set a timeframe and click the focus button
    - All selected apps will be deactivated until the period is finished or you manually stop the focus period
    - The focus period can be stopped by holding down on the stop button
